# Getting Started with Templ Router

**A comprehensive guide to setting up and integrating Templ Router into your Go project.**

## Overview

Templ Router is a production-ready Go library for file-based routing with [templ](https://templ.guide/) templates, dependency injection, and comprehensive middleware support. This guide will walk you through setting up a new project from scratch.

## Prerequisites

- **Go 1.24+** with modern Go features
- Basic understanding of Go modules and web development
- [templ template engine](https://templ.guide/) installed

## Step 1: Create Your Go Project

```bash
# Create your project directory
mkdir your-project
cd your-project

# Initialize Go module
go mod init github.com/youruser/yourproject
```

## Step 2: Install Dependencies

```bash
# Install templ-router library
go get github.com/denkhaus/templ-router

# Install required tools
go install github.com/a-h/templ/cmd/templ@latest
go install github.com/denkhaus/templ-router/cmd/trgen@latest

# Optional: Install air for hot reload during development
go install github.com/air-verse/air@latest
```

## Step 3: Create Project Structure

```bash
# Create the basic project structure
mkdir -p app
mkdir -p pkg/dataservices
mkdir -p generated/templates
```

Your project should now look like this:

```
your-project/
├── go.mod                      # Your module
├── main.go                     # Your application entry point
├── app/                        # Your templates directory
├── pkg/
│   └── dataservices/           # Your data services
└── generated/                  # Generated by trgen
    └── templates/
```

## Step 4: Create Basic Templates

### Create a Layout Template

```go
// app/layout.templ
package main

import "github.com/a-h/templ"

templ Layout(content templ.Component) {
    <!DOCTYPE html>
    <html lang="en">
    <head>
        <meta charset="UTF-8"/>
        <meta name="viewport" content="width=device-width, initial-scale=1.0"/>
        { title := metadata.M(ctx, "title") }
        if title != "" {
            <title>{ title }</title>
        } else {
            <title>{ i18n.T(ctx, "site_title") }</title>
        }
        <script src="https://cdn.tailwindcss.com"></script>
    </head>
    <body class="bg-gray-50">
        <nav class="bg-white shadow-sm border-b">
            <div class="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8">
                <div class="flex justify-between h-16">
                    <div class="flex items-center">
                        <h1 class="text-xl font-semibold">Your App</h1>
                    </div>
                </div>
            </div>
        </nav>
        <main class="max-w-7xl mx-auto py-6 sm:px-6 lg:px-8">
            { content }
        </main>
    </body>
    </html>
}
```

## Step 5: Generate Template Registry

```bash
# Generate template registry from your app directory
trgen --scan-path=app --module-name=github.com/youruser/yourproject
```

This will create `generated/templates/registry.go` with template mappings.

## Step 6: Create Main Application

```go
// main.go
package main

import (
    "context"
    "net/http"

    "github.com/denkhaus/templ-router/pkg/di"
    "github.com/denkhaus/templ-router/pkg/router/middleware"
    "github.com/go-chi/chi/v5"
    "github.com/samber/do/v2"

    // Import your generated template registry
    "github.com/youruser/yourproject/generated/templates"
)

func main() {
    // Create DI container with router services
    container := di.NewContainer()
    defer container.Shutdown()

    // Register router services with config prefix
    container.RegisterRouterServices("TR")

    // Create your template registry
    templateRegistry, err := templates.NewRegistry(container.GetInjector())
    if err != nil {
        panic(err)
    }

    // Register application services using options pattern
    container.RegisterApplicationServices(
        di.WithTemplateRegistry(templateRegistry),
    )

    // Create Chi router
    mux := chi.NewRouter()

    // Add auth context middleware
    authMiddleware, err := middleware.NewAuthContextMiddleware(container.GetInjector())
    if err != nil {
        panic(err)
    }
    mux.Use(authMiddleware.Middleware)

    // Get clean router and initialize
    cleanRouter := container.GetRouter()
    if err := cleanRouter.Initialize(); err != nil {
        panic(err)
    }

    // Register file-based routes
    if err := cleanRouter.RegisterRoutes(mux); err != nil {
        panic(err)
    }

    // Start server
    http.ListenAndServe(":8080", mux)
}
```

## Step 7: Run Your Application

```bash
# Generate templ files first
templ generate

# Build and run
go build
./your-project

# Or use air for hot reload
air
```

Visit `http://localhost:8080` to see your application!

## Step 8: Add Dynamic Routes

### Create Dynamic Route with Parameters

```go
// app/user/id_/page.templ
package main

templ Page(userID string) {
    <div class="bg-white shadow rounded-lg p-6">
        <h1 class="text-2xl font-bold mb-4">User Profile</h1>
        <p class="text-gray-600">Viewing user ID: { userID }</p>
    </div>
}
```

### Create Template Metadata

```yaml
# app/user/id_/page.templ.yaml
metadata:
  page_title: "User Profile"
  description: "User profile page"

auth:
  type: "UserRequired"
  redirect_url: "/login"
```

Regenerate the template registry after adding new templates:

```bash
trgen --scan-path=app --module-name=github.com/youruser/yourproject
```

## Step 9: Add Data Services

### Create Data Service Interface

```go
// pkg/dataservices/user_service.go
package dataservices

import (
    "github.com/denkhaus/templ-router/pkg/interfaces"
)

type UserData struct {
    ID    string
    Name  string
    Email string
}

type UserDataService interface {
    GetData(routerCtx interfaces.RouterContext) (*UserData, error)
    GetUserData(routerCtx interfaces.RouterContext) (*UserData, error)
}

type userDataServiceImpl struct{}

func NewUserDataService(injector *do.Injector) (UserDataService, error) {
    return &userDataServiceImpl{}, nil
}

func (s *userDataServiceImpl) GetUserData(routerCtx interfaces.RouterContext) (*UserData, error) {
    userID := routerCtx.GetURLParam("id")

    return &UserData{
        ID:    userID,
        Name:  "User " + userID,
        Email: "user" + userID + "@example.com",
    }, nil
}

func (s *userDataServiceImpl) GetData(routerCtx interfaces.RouterContext) (*UserData, error) {
    return s.GetUserData(routerCtx)
}
```

### Update Template to Use Data

```go
// app/user/id_/page.templ
package main

templ Page(user *UserData) {
    <div class="bg-white shadow rounded-lg p-6">
        <h1 class="text-2xl font-bold mb-4">{ user.Name }</h1>
        <p class="text-gray-600">Email: { user.Email }</p>
        <p class="text-gray-600">ID: { user.ID }</p>
    </div>
}
```

### Register Data Service

Update your `main.go`:

```go
// Add this after container.RegisterApplicationServices()
injector := container.GetInjector()
do.ProvideNamed(injector, "UserDataService", dataservices.NewUserDataService)
```

## Step 10: Add Internationalization

### Create Internationalized Routes

```bash
mkdir -p app/locale_/user/id_
```

```go

  type: "UserRequired"
  redirect_url: "/login"
```

## Development Workflow

### Daily Development Commands

```bash
# 1. Generate templates (after changing .templ files)
templ generate

# 2. Generate template registry (after adding/removing templates)
trgen --scan-path=app --module-name=github.com/youruser/yourproject

# 3. Run with hot reload
air
```

### Watch Mode for Development

```bash
# Run trgen in watch mode for automatic registry generation
trgen --scan-path=app --module-name=github.com/youruser/yourproject --watch
```

## Troubleshooting

### Common Issues

**Issue**: `trgen: command not found`
```bash
# Install trgen manually
go install github.com/denkhaus/templ-router/cmd/trgen@latest
```

**Issue**: Template registry not found
```bash
# Ensure you're running trgen from your project directory
cd your-project  # where go.mod is located
trgen --scan-path=app --module-name=github.com/youruser/yourproject
```

**Issue**: Routes not working after adding templates
```bash
# Regenerate template registry after adding/removing templates
trgen --scan-path=app --module-name=github.com/youruser/yourproject
```
